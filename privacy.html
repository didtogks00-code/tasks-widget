Privacy Policy

Tasks Widget is a personal desktop app used only by its developer.

  • It uses the Google Tasks API (scope: https://www.googleapis.com/auth/tasks) only to show, add and complete the signed-in user's own tasks.
  • Data is exchanged directly between the user's computer and Google. Nothing is sent to, stored on, or shared with any other server or third party.
  • The OAuth token is stored only on the user's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

개인정보처리방침

이 앱은 개발자 본인만 사용하는 데스크톱 위젯으로, 로그인한 사용자의 Google Tasks를 보고 추가·완료하는 데에만 Google Tasks API를 사용합니다. 데이터는 사용자 컴퓨터와 Google 사이에서만 오가며, 다른 서버나 제3자에게 전송·저장·공유되지 않습니다.
